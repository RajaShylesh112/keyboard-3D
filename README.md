# KX-01 Mechanical Keyboard · 3D scrollytelling

Experimental landing page that tells the story of the KX-01 mechanical keyboard through a cinematic, scroll-driven 3D image sequence.

Scroll controls a full-screen canvas that plays the keyboard exploding into an engineering diagram and reassembling, with Apple-style dark UI and synchronized copy.
